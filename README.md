# Meu Primeiro Projeto CSS 🎨

Este repositório guarda um marco muito importante na minha jornada na tecnologia: o meu primeiríssimo contato prático com a estilização de páginas web usando CSS puro!

## 🧠 O que este projeto representa?
Como estou me candidatando para vagas de Jovem Aprendiz, acredito que mostrar de onde comecei é tão importante quanto mostrar onde estou agora. Este projeto foi a minha base para compreender conceitos essenciais que utilizo até hoje, como:

- Como vincular um arquivo de estilo externo ao HTML.
- O funcionamento dos seletores básicos (tags, classes e IDs).
- Manipulação de cores, fontes e propriedades iniciais do Box Model (como `margin` e `padding`).
- A importância da persistência nos primeiros códigos que dão errado antes de darem certo.

## 🚀 Tecnologias Utilizadas
- HTML5 (Estruturação)
- CSS3 (Estilização básica)
